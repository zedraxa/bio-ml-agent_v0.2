# Bio-ML Agent — Golden Path Demo 🌟

Bu dizin, ajanın veri bilimi ve biyoinformatik yeteneklerini en hızlı şekilde deneyimlemeniz için hazırlandı.

## 🚀 Hızlı Başlangıç

1.  **Sanal Ortamı Aktif Edin:**
    ```bash
    source .venv/bin/activate
    ```

2.  **Demo Verisini Üretin:**
    ```bash
    python examples/golden_path_demo/generate_demo_data.py
    ```

3.  **UI Başlatın ve Senaryoyu Takip Edin:**
    `demo_scenario.md` dosyasındaki promptları kullanarak analize başlayın.

## 📦 İçindekiler
- `generate_demo_data.py`: Gerçekçi meme kanseri veri seti üretici.
- `demo_scenario.md`: Adım adım ajan komutları.
- `breast_cancer_data.csv`: (Üretim sonrası) Analiz edilecek veri seti.

## 💡 Neden Bu Demo?
- **İzole:** Ana projeye ve repoya dokunmaz.
- **Gerçekçi:** Biyomedikal bir problem üzerinden ajan performansını gösterir.
- **Hızlı:** Tüm pipeline 5 dakika içinde tamamlanabilir.
