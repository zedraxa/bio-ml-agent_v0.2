## 🔬 PHASE 2: BIO-ML DEEP SPECIALIZATION (ACTIVE)
Transitioning from a "General Agent" to a "Bioengineering-Grade Autonomous Lab & Analysis Copilot".

### 🧪 AXIS A: MICROSCOPY INTELLIGENCE (Deep Image Understanding)
The agent goes beyond saying "cell" — it understands, counts, and measures the full structure.
- [ ] **A1: Microscopy Perception** — Modality detection (Brightfield, Fluorescence, Confocal, SEM, Histology) and quality scoring (blur, exposure, staining artifacts, debris).
- [ ] **A2: Fine-Grained Identification** — Cellular structures (nucleus, nucleolus, cytoplasm, mitotic spindles, apoptotic bodies) and developmental stages (Prophase → Cytokinesis).
- [ ] **A3: Segmentation & Morphometrics** — Cell/nucleus masking, quantitative outputs: cell count, nucleus/cell ratio, area, perimeter, mitotic index.
- [ ] **A4: Microscopy Critique & Reporting** — Uncertainty mapping, false-positive auditing, annotated academic reports with measurement tables.

### 💻 AXIS B: ADVANCED CODING INTELLIGENCE (Scientific Code Agency)
- [ ] **B1: Code Architect** — Designs modular architecture and interfaces for large code generation requests.
- [ ] **B2: Scientific & Bio Coder** — Expert-level usage of NumPy, Pandas, Scikit-Learn, and Biopython.
- [ ] **B3: Self-Debugging & Refactor** — Agent repairs its own code via a `Lint → Test → Run` loop.
- [ ] **B4: Benchmarking** — Performance, runtime, and reproducibility auditing of generated code.

### 🧬 AXIS C: DOMAIN-SPECIALIZED BIO AGENTS (Vertical Expertise)
- [ ] **C1: Cell Biology & Histology** — Cell culture, confluency analysis, and tissue layer interpretation.
- [ ] **C2: Molecular Biology** — DNA/RNA workflows, primer design logic, sequence interpretation.
- [ ] **C3: Biomedical Signals** — EMG/ECG/PPG signal processing, peak detection, feature extraction.
- [ ] **C4: Tissue Engineering** — Scaffolding metrics and biomaterial comparison tables.
- [ ] **C5: Biostatistics** — Appropriate test selection (t-test, ANOVA), effect size, and variance analysis.

### 🔄 AXIS D: SCIENTIFIC WORKFLOW AUTOMATION (End-to-End Pipelines)
- [ ] **D1: Literature-to-Protocol** — Extract lab steps and reagent tables directly from scientific papers.
- [ ] **D2: Microscopy-to-Insight** — Fully automated pipeline from raw image to quantified analysis report.
- [ ] **D3: Dataset-to-Model** — Complete pipeline: data profiling, model training, explainability reporting.
