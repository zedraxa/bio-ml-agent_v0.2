# Kişilik Bölünmesi Araştırma Raporu Projesi

1.  **Araştırma:** `WEB_SEARCH` aracını kullanarak Dissosiyatif Kimlik Bozukluğu (DKB) hakkında belirtiler, nedenler, teşhis kriterleri (DSM-5), tedavi yöntemleri ve yaygın yanlış anlamalar üzerine bilgi topla.
2.  **Raporlama (Markdown):** Toplanan bilgileri `rapor.md` dosyasına yapılandırılmış bir şekilde (başlıklar, alt başlıklar, listeler) yaz.
3.  **PDF Dönüşümü:** `BASH` komutu ile `pandoc` kullanarak `rapor.md` dosyasını `rapor.pdf` dosyasına dönüştür. Gerekirse `pandoc` ve LaTeX bağımlılıklarını kur.
4.  **Sonuç:** Kullanıcıya `rapor.md` ve `rapor.pdf` dosyalarının hazır olduğunu bildir.
